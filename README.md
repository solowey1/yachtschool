# yachtschool — тренажёр МСС-65

Telegram-бот для изучения Международного свода сигналов 1965 года (МСС-65). Спроектирован так, чтобы со временем легко добавлять другие разделы морских правил (МППСС, метеосигналы, флаги расцвечивания и т. д.).

## Что умеет

В главном меню (`/menu`) — пять тренажёров:

- 🚩 **Флаги** — узнавайте сигнальный флаг по букве и наоборот
- 📛 **Названия букв** — фонетический алфавит (Альфа / Браво / …)
- 📡 **Азбука Морзе** — комбинации точек и тире
- 📜 **Однобуквенные сигналы** — значение каждого флага как самостоятельного сообщения
- 🔤 **Буквы (смешанный режим)** — вопросы из всех разделов вперемешку

Каждый день в **17:00 по Москве** бот присылает пользователю 5 вопросов: 4 ранее не задававшихся комбинации (тренажёр × буква) и 1 на повторение — недавно отвеченный неправильно вопрос (или просто ещё одна свежая позиция, если ошибок не было). Команда `/stats` показывает накопленную статистику.

## Архитектура

```
app/
├── bot/             # aiogram-маршрутизация, middleware, клавиатуры, callbacks
├── db/              # модели и сессия SQLAlchemy 2.x (async)
├── i18n/            # JSON-локали + lookup-движок
├── repositories/    # CRUD/запросы к Postgres
├── services/        # picker (выбор вопросов), quiz_engine, scheduler
└── training/        # фреймворк тренажёров
    ├── base.py      #   абстракции Trainer / Topic / Question
    ├── registry.py  #   глобальный реестр
    └── mcs65/       #   первый предмет — МСС-65 (данные, рендер флагов, тренажёры)
```

Добавление нового раздела (например, МППСС-72) — это новый каталог в `app/training/<subject>/` с собственным набором тренажёров; они регистрируются в реестре, и автоматически появляются в меню. Никаких изменений в коде бота не требуется.

Тексты, названия букв и значения сигналов лежат в `app/i18n/locales/ru.json`. Для добавления английского достаточно положить `en.json` рядом — переводчик подхватит его автоматически.

## Запуск

### Локально через Docker Compose

1. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`:

   ```bash
   cp .env.example .env
   ```

2. Поднимите всё:

   ```bash
   docker compose up -d --build
   ```

   Compose поднимет Postgres 16 + бот. Миграции Alembic накатываются автоматически при старте контейнера. Флаги генерируются в `assets/flags/` при первом запуске и кешируются.

3. Логи:

   ```bash
   docker compose logs -f bot
   ```

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен бота от `@BotFather` |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | `yachtschool` | креды Postgres |
| `DAILY_DELIVERY_TIME` | `17:00` | когда слать ежедневную пятёрку (часы:минуты) |
| `DAILY_DELIVERY_TIMEZONE` | `Europe/Moscow` | зона времени для расписания |
| `DAILY_QUESTIONS_COUNT` | `5` | сколько вопросов слать в день |
| `DEFAULT_LANGUAGE` | `ru` | код локали по умолчанию |
| `LOG_LEVEL` | `INFO` | уровень логирования |

### Nginx

Бот работает в режиме long polling и не требует входящего HTTP. Если в будущем понадобится webhook, добавьте сервис `nginx` снаружи compose — порты `bot` для этого не публикуются.

## База данных

Три таблицы:

- `users` — Telegram-пользователи, их язык и флаг ежедневной рассылки
- `question_answers` — каждый ответ; идентичность вопроса = `(trainer_key, entry_code)`
- `daily_deliveries` — отметки доставленных пятёрок (защита от дублей при перезапуске)

Миграции живут в `alembic/versions/`. Создать новую:

```bash
docker compose exec bot alembic revision --autogenerate -m "your_change"
```

## Локаль

Все пользовательские тексты — в `app/i18n/locales/<lang>.json` под точечными ключами. Имена букв и тексты сигналов МСС-65 — в `mcs65.name.*` и `mcs65.meaning.*`. Сейчас доступен только `ru`.

## Лицензия и источники

Тексты однобуквенных сигналов адаптированы из МСС-65 (Международный свод сигналов, ред. 1965 г.). Графика флагов отрисовывается программно по описаниям из свода.
